## 1. 概述

现有插件只支持单一 `default` 存档的保存 / 加载（工具条按钮），无法管理多套蓝图。本需求引入 **ComfyUI 式的「已保存蓝图（工作流）列表」**：多个命名存档以列表形式展示在左侧面板上方，点选加载切换画布内容，并提供另存为 / 重命名 / 删除管理操作。既有「节点」列表（节点实例清单）保留，下移为左栏下方区域。

价值：

1. **多工作流管理**：用户可维护多套处理管线（如「人像磨皮」「边缘提取实验」），一键切换；
2. **样板价值**：示范 DataProvider 插件资产区（`graphs/` 命名空间）的多存档组织方式；
3. **跨插件可编程**：存档枚举 / 重命名 / 删除进入 service_api，MCP 客户端可远程管理工作流。

### 1.1 非目标（Out of Scope）

- 不做存档导入 / 导出（文件拷贝即可，不在 UI 提供）；
- 不做存档缩略图、预览、标签、搜索；
- 不做自动保存 / 脏标记提示（切换存档前不拦截未保存修改）；
- 不做存档版本历史。

## 2. 用户故事

| 编号 | 角色 | 故事 | 验收要点 |
|------|------|------|----------|
| US-1 | 最终用户 | 在左栏「蓝图」列表看到全部已保存存档，每行显示名称、节点数与保存时间 | 枚举 DataProvider 资产区 `graphs/` 下全部 `*.json` |
| US-2 | 最终用户 | 点击工具条「另存为」或列表区「另存为」，输入名称把当前画布存为命名存档 | 重名时弹覆盖确认；保存后列表即时刷新 |
| US-3 | 最终用户 | 选中存档点「加载」或直接双击条目，画布切换为该存档内容 | 加载后节点列表 / 参数面板同步复位；缺失 / 损坏存档回退示例图并提示 |
| US-4 | 最终用户 | 选中存档点「重命名」输入新名 | 重名冲突中文报错且不生效；成功后列表刷新 |
| US-5 | 最终用户 | 选中存档点「删除」，确认后存档移除 | 需确认对话框；删除后列表减少 |
| US-6 | 最终用户 | 重新打开插件，若存在 `default` 存档则自动恢复它，否则看到预置示例图 | 与既有回退行为一致 |
| US-7 | 插件开发者 / MCP 客户端 | 经 service_api 枚举 / 重命名 / 删除存档 | `list_graphs` / `rename_graph` / `delete_graph` 声明与实现逐参数一致 |

## 3. 功能需求

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-1 | 存档列表每行展示：名称、节点数、保存时间（存档文件元信息） | P0 |
| FR-2 | 「另存为」：命名对话框保存当前画布；重名弹覆盖确认；工具条原「保存图」改为该语义 | P0 |
| FR-3 | 「加载」：选中行加载到画布；双击条目等效 | P0 |
| FR-4 | 「重命名」：对话框输入新名，重名冲突 / 非法名中文报错 | P0 |
| FR-5 | 「删除」：确认对话框后删除存档文件 | P0 |
| FR-6 | 启动行为：存在 `default` 存档自动加载，否则构建预置示例图 | P0 |
| FR-7 | 左栏布局：上「蓝图」区（存档列表 + 按钮行）+ 下「节点」区（既有 NodeListPanel），栏宽 200px 不变 | P0 |
| FR-8 | 工具条精简：移除「加载图」按钮（加载由列表承担），保留 运行 / 停止 / 另存为 / 适应视图 | P0 |
| FR-9 | 无存档时显示占位提示「暂无已保存蓝图」 | P1 |
| FR-10 | service_api 新增 `list_graphs` / `delete_graph` / `rename_graph`（`save_graph` / `load_graph` 已具备 name 参数，不变） | P0 |

## 4. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-1 | 存档文件操作全部经 DataProvider 插件资产目录（`assets_dir/<plugin_id>/graphs/`），不直接拼 `data/` 路径 |
| NFR-2 | 图名校验：拒绝空名与含 `<>:"/\|?*` 的名称（Windows 文件系统安全） |
| NFR-3 | 操作失败（加载 / 保存 / 重命名 / 删除）一律中文弹窗 + ERROR 日志 |
| NFR-4 | 遵守插件规范：import 置顶、函数 ≤ 20 行、嵌套 ≤ 3 层、无魔法数、中文 docstring、type hints、槽函数 ≤ 5 行委托 |
| NFR-5 | 向后兼容：既有 `default` 存档可直接被列表枚举与加载；service_api 既有六个方法签名不变 |
