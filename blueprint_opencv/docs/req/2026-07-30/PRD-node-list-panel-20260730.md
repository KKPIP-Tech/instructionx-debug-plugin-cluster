## 1. 概述

在 Blueprint OpenCV 插件主界面新增**蓝图节点列表面板**（下称「列表」）：以清单形式展示画布上的全部节点实例（标题、类型名、运行状态），并提供「定位 / 重命名 / 删除」管理操作。

价值：

1. **全局概览**：画布缩放 / 平移后节点散落在视野外，列表提供不依赖视口的全量节点清单，节点数量与运行状态一目了然；
2. **管理入口**：对视野外节点也能直接定位、重命名、删除，不必先缩放画布寻找；
3. **示范价值**：作为 Blueprint 组件的样板插件，补充演示 `graph.node_added / node_removed`、`node.status_changed`、`canvas.selection_changed / select_nodes / center_on` 的用法。

### 1.1 非目标（Out of Scope）

- 不做面板折叠 / 展开（固定展示，保持简单）；
- 不做列表多选、拖拽排序、搜索过滤；
- 不做边（edge）的展示与管理；
- 不新增 service_api（列表是纯视图能力，运行状态经既有 `node_status_changed` 信号链自然反映）。

## 2. 用户故事

| 编号 | 角色 | 故事 | 验收要点 |
|------|------|------|----------|
| US-1 | 最终用户 | 打开插件后在左侧列表看到画布全部节点，每行显示标题、类型名与运行状态 | 预置示例图显示 5 行；状态 idle/running/done/error 用颜色区分 |
| US-2 | 最终用户 | 在画布上新增 / 删除 / 重命名节点，或运行管线改变节点状态时，列表自动刷新 | 无需手动刷新；运行中状态实时变化 |
| US-3 | 最终用户 | 在画布中选中节点，列表对应行高亮；点击列表行，画布反向选中该节点 | 双向同步，不出现信号循环 / 界面卡死 |
| US-4 | 最终用户 | 选中列表行后点击「定位」，画布视图居中到该节点 | 缩放不变，节点居中可见 |
| US-5 | 最终用户 | 选中列表行后点击「重命名」，输入新标题生效 | 画布节点标题与列表同步更新；空标题不生效 |
| US-6 | 最终用户 | 选中列表行后点击「删除」，节点连同其连线被移除 | start 节点同样可删除；列表与画布同步更新 |
| US-7 | 最终用户 | 画布为空时列表显示占位提示 | 显示「画布暂无节点」 |

## 3. 功能需求

| 编号 | 需求 | 优先级 |
|------|------|--------|
| FR-1 | 列表每行展示：节点标题、类型名（`type_name`）、运行状态（idle/running/done/error，颜色区分） | P0 |
| FR-2 | `graph.node_added` / `graph.node_removed` 时自动增删行 | P0 |
| FR-3 | 节点重命名（`node.title` 变化）与状态变化（`node.status_changed`）时对应行自动刷新 | P0 |
| FR-4 | 画布选中节点 → 列表对应行高亮；点击列表行 → `canvas.select_nodes` 反向选中 | P0 |
| FR-5 | 「定位」：`canvas.center_on` 居中到选中行节点 | P0 |
| FR-6 | 「重命名」：对话框输入新标题写回 `node.title` | P0 |
| FR-7 | 「删除」：`graph.remove_node`（UIKit 已连带清理边），start 节点不特殊化 | P0 |
| FR-8 | 画布为空时显示「画布暂无节点」占位提示 | P0 |
| FR-9 | 面板位于画布左侧，固定宽 200px（命名常量），与右侧参数 / 预览面板对称 | P0 |
| FR-10 | 未选中行时三个操作按钮禁用 | P1 |

## 4. 非功能需求

| 编号 | 需求 |
|------|------|
| NFR-1 | 纯视图层：只调用 `BlueprintGraph` / `BlueprintCanvas` 公开 API，不触碰 cv2 / 执行引擎 / service |
| NFR-2 | 双向同步必须防止信号循环（标志位守卫），任何操作序列不死循环 |
| NFR-3 | 组件全部来自 InstructionX_UIKit（ListWidget / Button 等），风格与既有面板一致 |
| NFR-4 | 遵守插件规范：import 置顶、函数 ≤ 20 行、嵌套 ≤ 3 层、无魔法数、中文 docstring、type hints、槽函数 ≤ 5 行委托 |
| NFR-5 | 主题感知：状态色取 UIKit 令牌（`color.primary / success / danger / text.tertiary`），light / dark 主题均正常 |
