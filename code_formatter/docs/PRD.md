# 代码格式化插件 — 产品需求文档

## 概述
提供常见编程语言的代码格式化功能，支持多种格式化风格。

## 功能需求
- **Python 格式化**：基于 black 风格的代码格式化。
- **JavaScript 格式化**：基于 prettier 风格的代码格式化。
- **语言选择**：支持在下拉框中选择目标语言。
- **复制结果**：一键复制格式化后的代码。

## 非功能需求
- 格式化失败时给出明确错误信息。
- 保留原始代码语义，不做逻辑修改。

## 依赖
- `core.plugin.plugin_interface.IPlugin`
- `PySide6.QtWidgets`
