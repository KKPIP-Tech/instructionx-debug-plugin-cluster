# 图片压缩插件 — 产品需求文档

## 概述
提供图片文件的压缩功能，支持调整压缩质量以平衡画质与文件大小。

## 功能需求
- **单张压缩**：选择图片文件，设置质量，输出压缩后的图片。
- **质量调节**：通过滑块调节压缩质量（1%–100%）。
- **格式支持**：支持 PNG、JPG、JPEG、BMP、WEBP。
- **预览**：显示压缩前后的文件大小对比。

## 非功能需求
- 压缩过程不阻塞 UI（异步处理）。
- 默认质量 85%，在画质和体积间取得平衡。

## 依赖
- `core.plugin.plugin_interface.IPlugin`
- `PySide6.QtWidgets`
- `PIL` (Pillow)
